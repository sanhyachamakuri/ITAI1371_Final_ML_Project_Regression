# Final ML Project — Used Vehicle Price Prediction

## Project Description
This project focuses on predicting used vehicle prices using machine learning regression techniques. The dataset was cleaned, preprocessed, and transformed before training multiple regression models. Different models were evaluated and compared using validation and test metrics.

The project follows a complete machine learning workflow including:
- Data preprocessing
- Feature scaling
- Train/Validation/Test split
- Model training
- Performance evaluation
- Ensemble learning methods
- Visualization and comparison of results

---

## Dataset Preparation
The dataset was cleaned and prepared for regression analysis. Numerical features were scaled using StandardScaler to improve model performance.

Dataset split:
- Training Set — 70%
- Validation Set — 15%
- Test Set — 15%

---

## Machine Learning Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- K-Nearest Neighbors Regressor
- Voting Ensemble Regressor
- Bayesian Ensemble Model

---

## Evaluation Metrics
The following metrics were used to compare models:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

Lower MAE and MSE values indicate better prediction accuracy, while higher R² values represent stronger model performance.

---

## Best Performing Model
The Bayesian Ensemble model achieved the best overall performance on both validation and test datasets. Ensemble learning improved prediction accuracy by combining predictions from multiple strong regression models.

The Decision Tree Regressor showed the weakest performance due to overfitting and lower generalization ability.
